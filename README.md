# PT. Hansindo Berkat Jaya Logistik — Company Website

Official company website for **PT. Hansindo Berkat Jaya Logistik**, a logistics service provider covering all of Indonesia. Built with [Next.js](https://nextjs.org).

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS
- **Font**: Inter (Google Fonts)

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
hansindo/
├── app/              # Next.js App Router pages & layouts
├── components/       # Reusable UI components
├── lib/              # Data & utility files
├── public/           # Static assets (images, icons)
└── types/            # TypeScript type definitions
```
